# Cloudflare Worker + D1, в первой версии — общий секретный ключ вместо входа

Нужен бесплатный бэкенд без своего домена, с данными, общими для телефона и ноутбука. Фронтенд и API отдаёт один Worker на `*.workers.dev`, пребывания хранятся в D1. Авторизацию отложили на вторую итерацию, но совсем открытый API на угадываемом адресе — это чтение и удаление данных кем угодно, поэтому API требует один длинный секретный ключ, который вводится один раз на устройстве; без него ответ 403. Во второй итерации включаем Cloudflare Access с одноразовым PIN на почту (Cloudflare сам шлёт письма, домен не нужен, бесплатно до 50 пользователей) и убираем проверку ключа.

## Considered Options

- **Только localStorage** — проще, но данные живут на одном устройстве и пропадают при очистке браузера.
- **Supabase + Gmail SMTP** — встроенный вход по коду, но бесплатный проект засыпает после недели низкой активности.
- **Свой OTP через Resend / Cloudflare Email Sending** — Resend без домена шлёт только на свой адрес; Cloudflare Email Sending на произвольные адреса только на платном плане.
- **Appwrite Cloud** — засыпает без активности в консоли, удаляется через 90 дней паузы.
